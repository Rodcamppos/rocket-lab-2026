# Rocket Lab 2026

Repositório destinado às atividades e projetos desenvolvidos durante o **Rocket Lab 2026.2**, curso intensivo promovido pela **Visagio** em Recife.

Aqui ficam reunidos os projetos práticos realizados ao longo do programa.

## Projetos

| Pasta | Projeto | Descrição |
|---|---|---|
| [`Projeto 01/`](./Projeto%2001) | **CineData Analytics** | Pipeline de dados end-to-end no Databricks (PySpark/SQL), com Arquitetura Medalhão (Bronze, Silver, Gold), modelagem dimensional (Star Schema) e tabela de contexto para um assistente de IA (RAG), a partir de uma base de filmes intencionalmente suja e fragmentada. |

> Novos projetos serão adicionados em pastas próprias (`Projeto 02/`, `Projeto 03/`, ...) conforme o programa avança.

## Sobre o Rocket Lab

O Rocket Lab é um programa intensivo de capacitação da Visagio voltado à formação prática em Engenharia de Dados, com atividades estruturadas em torno de ferramentas e desafios reais do mercado.
